CÁC LỆNH CURL ĐỂ TEST API TRONG POSTMAN

Lưu ý: Thay thế http://localhost:3000 bằng URL thực tế của server nếu khác
Thay thế các giá trị như customerId, productId, orderId bằng các ID thực tế từ database

1. FORM TẠO ĐƠN HÀNG (POST /orders)

curl --location 'http://localhost:3000/orders' \
--header 'Content-Type: application/json' \
--data '{
    "customerId": "123e4567-e89b-12d3-a456-426614174000",
    "items": [
        {
            "productId": "223e4567-e89b-12d3-a456-426614174001",
            "quantity": 2
        },
        {
            "productId": "323e4567-e89b-12d3-a456-426614174002",
            "quantity": 1
        }
    ],
    "notes": "Giao hàng vào buổi sáng"
}'

2. FORM XEM DANH SÁCH SẢN PHẨM (GET /products)

curl --location 'http://localhost:3000/products?page=1&limit=10&categoryId=123e4567-e89b-12d3-a456-426614174000'

Hoặc không có categoryId:
curl --location 'http://localhost:3000/products?page=1&limit=10'

3. FORM XEM CHI TIẾT ĐƠN HÀNG (GET /orders/:id)

curl --location 'http://localhost:3000/orders/123e4567-e89b-12d3-a456-426614174000'

4. FORM CẬP NHẬT TRẠNG THÁI ĐƠN HÀNG (PATCH /orders/:id/status)

curl --location --request PATCH 'http://localhost:3000/orders/123e4567-e89b-12d3-a456-426614174000/status' \
--header 'Content-Type: application/json' \
--data '{
    "status": "CONFIRMED"
}'

Các giá trị status có thể: "PENDING", "CONFIRMED", "PROCESSING", "SHIPPED", "DELIVERED", "CANCELLED"

5. FORM NHẬP KHO (POST /inventory/import)

curl --location 'http://localhost:3000/inventory/import' \
--header 'Content-Type: application/json' \
--data '{
    "productId": "223e4567-e89b-12d3-a456-426614174001",
    "quantity": 100,
    "supplierId": "423e4567-e89b-12d3-a456-426614174003",
    "reason": "Nhập hàng từ nhà cung cấp",
    "notes": "Hàng mới về"
}'

6. FORM XEM BÁO CÁO DOANH SỐ (GET /reports/sales)

curl --location 'http://localhost:3000/reports/sales?startDate=2024-01-01&endDate=2024-12-31'

7. FORM TẠO KHUYẾN MÃI (POST /promotions)

curl --location 'http://localhost:3000/promotions' \
--header 'Content-Type: application/json' \
--data '{
    "name": "Giảm giá 20% cho sản phẩm điện tử",
    "description": "Áp dụng cho tất cả sản phẩm trong danh mục điện tử",
    "type": "PERCENTAGE",
    "value": 20,
    "startDate": "2024-01-01T00:00:00Z",
    "endDate": "2024-12-31T23:59:59Z",
    "categoryId": "123e4567-e89b-12d3-a456-426614174000",
    "minPurchaseAmount": 500000

--data '{

    "description": "Khuyến mãi đặc biệt",
    "type": "FIXED_AMOUNT",
    "value": 50000,
    "startDate": "2024-01-01T00:00:00Z",
    "endDate": "2024-12-31T23:59:59Z",
    "productId": "223e4567-e89b-12d3-a456-426614174001"

8. FORM XEM DASHBOARD (GET /reports/dashboard)

curl --location 'http://localhost:3000/reports/dashboard'

HƯỚNG DẪN SỬ DỤNG TRONG POSTMAN

1. Import vào Postman:
   - Mở Postman
   - Click "Import" ở góc trên bên trái
   - Chọn tab "Raw text"
   - Copy và paste từng lệnh curl vào
   - Postman sẽ tự động chuyển đổi thành request

2. Hoặc tạo request thủ công:
   - Click "New" → "HTTP Request"
   - Chọn method (GET, POST, PATCH, DELETE)
   - Nhập URL
   - Với POST/PATCH: Vào tab "Body" → chọn "raw" → chọn "JSON" → paste JSON body
   - Với GET: Vào tab "Params" để thêm query parameters

3. Lưu ý:
   - Đảm bảo server đang chạy trước khi test
   - Thay thế các UUID mẫu bằng các ID thực tế từ database
   - Kiểm tra Content-Type header là "application/json" cho POST/PATCH requests
   - Với các request cần authentication, thêm header Authorization nếu có
