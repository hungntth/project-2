MÔ HÌNH MỨC ĐỈNH (DFD Level 0)

Hệ thống Thống kê Dashboard

Chú giải ký hiệu:
Quy trình xử lý (Process)
Tác nhân bên ngoài (External Entity)
Kho dữ liệu (Data Store)
Luồng dữ liệu (Data Flow)

Mô tả các chức năng chính:

  • Tổng quan doanh thu: Hiển thị tổng doanh thu, doanh thu theo ngày/tháng/năm
  • Thống kê đơn hàng: Tổng số đơn hàng, đơn hàng mới, đơn hàng theo trạng thái
  • Thống kê khách hàng: Tổng số khách hàng, khách hàng mới, khách hàng tiềm năng
  • Thống kê sản phẩm: Tổng số sản phẩm, sản phẩm bán chạy, sản phẩm theo danh mục
  • Thống kê kho hàng: Tổng giá trị tồn kho, cảnh báo tồn kho thấp, sản phẩm sắp hết
  • Đơn hàng gần đây: Hiển thị các đơn hàng mới nhất với thông tin chi tiết
  • Biểu đồ trực quan: Biểu đồ cột, đường, tròn để hiển thị dữ liệu thống kê
  • Báo cáo theo thời gian: So sánh dữ liệu theo ngày, tuần, tháng, năm
  • Tích hợp đa nguồn: Tổng hợp dữ liệu từ nhiều module khác nhau
  • Xuất báo cáo: Xuất báo cáo dashboard ra file PDF, Excel
